# 🎮 쿼리도 게임플레이 가이드

## 🎯 게임 목표

- **플레이어 목표**: 빨간색 네모(상단)에서 출발하여 파란색 동그라미로 표현된 말을 **하단 끝에 도달**
- **AI 목표**: 초록색 동그라미 말을 **상단 끝에 도달**

---

## 🕹️ 게임 조작

### 말 이동하기

1. **플레이어 턴 대기**
   - 화면에 "👤 당신" 표시 확인
   - **파란색 동그라미**: 당신의 말 (웃는 얼굴)
   - **초록색 동그라미**: AI의 말 (정사각형 눈)

2. **유효한 이동 확인**
   - **초록색 작은 원**: 이동 가능한 위치
   - **초록색 고리**: 이동 범위 표시

3. **말 이동 - 드래그 방식**
   - **파란색 동그라미를 클릭하고 드래그**
   - 초록색 원(유효한 위치)으로 드래그
   - 마우스를 놓으면 해당 위치로 이동
   - AI가 자동으로 턴 진행 (약 0.5초 후)

### 벽 배치하기

1. **벽 배치 모드 선택**
   - "← 수평 벽 →" 또는 "↑ 수직 벽 ↓" 버튼 클릭
   - 버튼이 파란색으로 변경되면 모드 활성화
   - 화면에 "수평 벽 배치 모드 활성" 메시지 표시

2. **보드에서 벽 위치 선택**
   - 보드의 **셀 사이**에 놓을 수 있는 영역이 나타남
   - **수평 벽**: 두 셀 위아래를 차단하는 위치
   - **수직 벽**: 두 셀 좌우를 차단하는 위치

3. **벽 배치**
   - 벽을 놓고 싶은 위치에 마우스 이동
   - 위치가 **초록색으로 강조**되면 배치 가능
   - **클릭하여 벽 배치**
   - **파란색** 벽이 보드에 나타남
   - AI의 벽은 **초록색**

4. **벽 배치 완료**
   - 벽을 설치하면 자동으로 이동 모드로 돌아감
   - AI턴 진행

## ⚠️ 게임 규칙

### 이동 규칙

1. **기본 이동**: 상/하/좌/우로 인접한 칸으로 이동
2. **점프 이동**: 상대 말이 앞에 있으면 그 위로 뛰어넘기 가능
3. **벽 차단**: 벽이 있는 방향으로는 이동 불가

### 벽 규칙

1. **최대 10개**: 각 플레이어당 벽 10개 보유
2. **완전 차단 금지**: 상대를 완전히 막는 벽은 설치 불가
   - 상대는 항상 목표에 도달할 경로가 있어야 함
3. **벽은 영구적**: 한 번 놓은 벽은 제거 불가
4. **벽의 크기**: 2칸을 차단 (가로 또는 세로)

### 승리 조건

- **플레이어 승리**: 파란색 말이 하단(행 8) 도달
- **AI 승리**: 초록색 말이 상단(행 0) 도달

## 💡 전략 팁

### 공격 전략

1. **가장 짧은 경로 유지**
   - 항상 목표로 가는 가장 직진 경로 선택

2. **벽으로 상대 지연**
   - 상대의 최단경로 앞에 벽 배치
   - 상대를 돌아가는 길로 강제

3. **초반부터 점프 노리기**
   - 상대 말에 접근하면 점프 기회 생김

### 방어 전략

1. **경로 확보**
   - 벽이 놓여도 항상 도달 가능한 길 유지

2. **벽 절약**
   - 10개 벽은 한정적
   - 필요한 순간에 사용

3. **상대의 최단경로 학습**
   - AI의 움직임 패턴 파악
   - 그 앞에 벽 설치

## 🎮 게임 난이도

### Easy AI
- **특징**: 거의 무작위로 움직임
- **강점**: 예측하기 어려움
- **약점**: 최적의 경로를 모름

### Normal AI
- **특징**: 목표로 가는 가장 짧은 경로 추구
- **강점**: 효율적으로 진행
- **약점**: 같은 전략 반복

## 🐛 버그 찾았나요?

만약 다음과 같은 문제가 생기면:

1. **벽이 보이지 않음** → 벽 배치 모드 버튼 확인
2. **말이 움직이지 않음** → 초록색 원(유효한 이동)만 클릭 가능
3. **AI가 움직이지 않음** → 0.5초 대기 후 자동 이동
4. **게임이 끝나지 않음** → 목표 행(상단/하단)에 정확히 도달했는지 확인
